New addition — Auto-apply to the triggering property
The bug: If a tenant starts this application wizard by hitting "Apply" on a specific property, completing the full application currently only creates a general/universal application — it does not count as having applied to that original property. The tenant then has to go back to that property and hit "Apply" a second time.
The fix: If the wizard was triggered from a specific property's "Apply" button, completing the wizard should automatically count as applying to that property — no second button press required.
Unaffected case: Once the general application is on file, applying to additional properties afterward should remain the current simple single-button "Apply" action (no need to redo the wizard).

On completion: Redirect to the Matches page, landing on Applied Matches, showing the property just applied to (which, per the fix above, should now correctly include the one that triggered the wizard).
